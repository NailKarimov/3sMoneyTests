## 🔴 Критические нарушения (WCAG 2.1 Level A)

### 1. **button-name** — Кнопки без видимого текста  
**Impact:** CRITICAL  
**Количество:** ~14 элементов  
**Правило:** [button-name - Buttons must have discernible text](https://dequeuniversity.com/rules/axe/4.13/button-name)

**Проблема:**
```html
<button type="button" class="Sidebar_closeButton__2uhpF">
  <!-- ❌ Нет текста, нет aria-label, нет title -->
</button>

<button class="icon-button flex items-align-center green border-radius-s">
  <!-- ❌ Иконочная кнопка без доступимого имени -->
</button>
```

**Решение (3 варианта):**
```html
<!-- Вариант 1: Видимый текст -->
<button type="button" aria-label="Close sidebar">
  <svg>...</svg>
</button>

<!-- Вариант 2: aria-label -->
<button type="button" class="Sidebar_closeButton" aria-label="Close">
  <svg>...</svg>
</button>

<!-- Вариант 3: title атрибут -->
<button type="button" class="Sidebar_closeButton" title="Close sidebar">
  <svg>...</svg>
</button>
```

**Где исправлять:**
- Sidebar close button
- Icon buttons в форме
- Dropdown trigger buttons

---

### 2. **label** — Form elements без label  
**Impact:** CRITICAL  
**Количество:** 1 элемент  
**Правило:** [label - Form elements must have labels](https://dequeuniversity.com/rules/axe/4.13/label)

**Проблема:**
```html
<input type="checkbox" name="" class="iconDark" value="">
<!-- ❌ Нет <label>, нет aria-label, нет title -->
```

**Решение:**
```html
<!-- Вариант 1: Explicit label -->
<label for="dark-mode">
  <input type="checkbox" id="dark-mode" class="iconDark">
  Dark mode
</label>

<!-- Вариант 2: aria-label -->
<input type="checkbox" aria-label="Dark mode" class="iconDark">

<!-- Вариант 3: Implicit label (обернуть input) -->
<label>
  <input type="checkbox" class="iconDark">
  Dark mode
</label>
```

## 🟠 Serious нарушения (WCAG 2.1 Level AA)

### 3. **link-name** — Ссылки без видимого текста  
**Impact:** SERIOUS  
**Количество:** ~8 элементов  
**Правило:** [link-name - Links must have discernible text](https://dequeuniversity.com/rules/axe/4.13/link-name)

**Проблема:**
```html
<a class="Link_link__s0GAk Link_dark__9L0c6" href="/">
  <!-- ❌ Иконочная ссылка без текста -->
</a>
```

**Решение:**
```html
<!-- Вариант 1: Добавить видимый текст -->
<a href="/" aria-label="Go to home">
  <svg>Home icon</svg>
  <span class="sr-only">Home</span>
</a>

<!-- Вариант 2: aria-label -->
<a href="/" aria-label="Home">
  <svg>...</svg>
</a>

<!-- Вариант 3: title атрибут + скрытый текст -->
<a href="/" title="Home">
  <svg>...</svg>
  <span class="sr-only">Home</span>
</a>
```

---

### 4. **nested-interactive** — Вложенные интерактивные элементы  
**Impact:** SERIOUS  
**Количество:** 2 элемента  
**Правило:** [nested-interactive - Interactive elements must not be nested](https://dequeuniversity.com/rules/axe/4.13/nested-interactive)

**Проблема:**
```html
<div role="button" tabindex="0" aria-haspopup="listbox">
  <!-- ❌ div с role="button" содержит кнопку или другой интерактивный элемент -->
  <button>Nested button</button>
</div>
```

**Решение — использовать правильную семантику:**
```html
<!-- ✅ Правильно: только одна интерактивная обертка -->
<button aria-haspopup="listbox" aria-expanded="false">
  Select option
</button>
```
