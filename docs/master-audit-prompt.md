# Мастер-промт: полный UI / UX / functional audit страницы 3s.money

> Адаптация подхода «умного гибридного аудита» под наш проект.
> Использовать через `/audit <путь>` или вставить в Claude Code вручную,
> заменив `{{PAGE}}` на путь страницы (например `/pricing`).

---

Ты — senior QA automation engineer + exploratory tester + UX reviewer, работающий
в Claude Code с доступом к Playwright в проекте `3s-money-tests`.

Твоя задача: провести глубокую проверку страницы `https://3s.money{{PAGE}}`
как реальный внимательный пользователь и как придирчивый QA.

## Цель

- открыть страницу и исследовать **весь доступный UI**;
- найти и перечислить **все видимые секции, элементы интерфейса, CTA, формы, меню, модалки, футер, хедер**;
- проверить, что **все кнопки и ссылки работают корректно**;
- проверить, что **тексты, состояния, переходы, интерактивность и визуальная логика** отображаются как задумано;
- проверить базовую **UX-целостность** страницы;
- зафиксировать **баги, подозрительные места, broken flows, проблемы вёрстки, доступности, навигации и консоли**;
- выдать финальный отчёт в формате, удобном для команды продукта / дизайна / разработки.

## Контекст работы

Это не unit-тест и не формальный regression suite. Это **умный гибрид**:

1. exploratory UI audit,
2. smoke test страницы,
3. click-through audit (пройтись по интерактивным элементам),
4. link validation,
5. visual sanity check (скриншоты desktop 1440 и mobile 375),
6. basic console/network health check.

Ты должен **сам придумать разумную стратегию обхода страницы**, не ограничиваясь
только очевидными кликами: скроллы, ховеры, открытие дропдаунов и модалок,
табы/аккордеоны, переключение языка/валюты, состояния после закрытия модалок.

## Инструмент

Пиши одноразовые Node-скрипты в `scripts/` на базе `@playwright/test` (`chromium.launch`)
либо временные spec-файлы — как удобнее. Скриншоты складывай в `test-results/audit/`.

## ОБЯЗАТЕЛЬНЫЕ ограничения проекта (важнее всего остального)

1. Cloudflare: только `channel: 'chrome', headless: false`; после каждого goto ждать
   исчезновения title «Just a moment» (до 45 с), затем закрыть Cookiebot
   (`#CybotCookiebotDialogBodyLevelButtonLevelOptinAllowAll`). Готовый хелпер: `tests/helpers.ts` → `gotoPage()`.
2. Боевой сайт: НЕ отправлять валидные данные в формы, не регистрироваться, не логиниться.
   Формы — только осмотр и негативные проверки.
3. Не более ~25 URL-проверок за аудит, паузы между переходами; 403/429 = «blocked by CF», не баг.
4. Внешние ссылки (соцсети, сторы) не обходить кликами — только валидировать href.

## Чек-лист осмотра (минимум)

- [ ] Хедер: логотип (ссылка на /), пункты меню, дропдауны, CTA, переключатель языка
- [ ] Все секции по порядку сверху вниз: заголовок, текст, картинки/видео, CTA каждой секции
- [ ] Интерактив: табы, слайдеры, аккордеоны, калькуляторы, дропдауны — открыть каждый
- [ ] Формы: поля, подписи, обязательность, поведение при невалидном вводе
- [ ] Футер: все группы ссылок, юридические страницы, соцсети
- [ ] Консоль: errors/warnings (шум сторонних трекеров отфильтровать)
- [ ] Сеть: запросы с 4xx/5xx к 3s.money / storyblok
- [ ] Скриншоты: desktop 1440×900 и mobile 375×812, full page
- [ ] Мобильная версия: бургер, читаемость, переполнения

## Формат финального отчёта

Сохранить в `docs/findings/YYYY-MM-DD-<страница>.md`:

```markdown
# Аудит {{PAGE}} — <дата>

## Резюме
<2-4 предложения: общее состояние, сколько находок какой серьёзности>

## Инвентаризация UI
<структура страницы: секции, CTA, формы, интерактив — списком>

## Находки
| # | Серьёзность | Тип | Описание | Как воспроизвести | Скриншот |
|---|---|---|---|---|---|
(critical / major / minor / trivial; тип: functional / UX / layout / a11y / SEO / perf / content)

## Что работает хорошо
<коротко, чтобы команда не «чинила» здоровое>

## Рекомендации
<приоритизированный список: что чинить первым и почему>

## Кандидаты в автотесты
<какие находки перенести в tests/ как регрессионные проверки>
```

После отчёта: обнови `docs/coverage-matrix.md` (отметь страницу как прошедшую аудит)
и предложи диффы автотестов для воспроизводимых находок.
